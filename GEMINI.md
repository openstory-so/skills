# OpenStory

The extension connects `https://openstory.so/mcp` (Streamable HTTP). When OpenStory MCP tools are connected, call those. They use this CLI's OAuth grant. Use the HTTP API in a skill only when those tools are absent, or the user gave a self-hosted origin.

Read the skill, then follow it:

- A script or brief into a multi-scene video: `skills/create-sequence/SKILL.md`
- A library style from references or a written look: `skills/create-style/SKILL.md`
- Sign-in, the current team, or a first sequence: `skills/setup/SKILL.md`
- Play stills, dialogue, music, and video as one cut: `skills/stitch/SKILL.md`
- Embed that player or export its MP4 from application code: `skills/stitch-player/SKILL.md`
